# Validation

Three validations are kept separate:

| Validation | Shows |
|---|---|
| Numerical | The solver reproduces reference solutions within declared tolerances |
| Model | Equations, parameters and transformations match the cited source |
| Comparison | Compared conditions and observables mean the same in both models |

## Numerical

- Independent reference: SciPy `solve_ivp` (Radau), generated by
  `tools/reference`. Fixtures are versioned with a manifest: generator,
  equations, Python and SciPy versions, tolerances and settings.
- Stiff test problems with known behaviour, separate from the Oregonator.
- The analytic Jacobian is checked against directional finite differences.
- Failures are explicit: budget exhausted, step too small, singular system,
  non-finite values, domain exit, cancelled. None of them becomes "no
  oscillation". Negative concentrations are never clipped silently.
- Reported coverage: number of cases per class (oscillating, steady,
  inconclusive) and the cases used for each error statistic.
- Speed comparisons state tolerances, horizons, outputs, hardware and versions.

## Robust classification protocol

A point is classified only when three runs agree: the base run, a run with
tighter tolerances, and a run with a doubled horizon. The horizon adapts to the
estimated period within fixed limits on simulated time and work; if the
criteria do not stabilise, the point is inconclusive.

## Control tests

The test suite must fail for each of these degenerate implementations:

- a write gate that rejects every command;
- a source parser that always abstains;
- a classifier that always answers inconclusive.

## Evaluations

Each evaluation reports its denominators, its cases and its limits.

| Evaluation | Compares |
|---|---|
| Search | Halton with transition refinement vs uniform sampling, same budget, counting all solver work |
| Context | Layered context vs full context, counting expansions |
| Evidence check | Strict parser vs open-weight review on messy sources |
| Agent | Muse Spark alone vs Muse Spark with the engine |

Results are added here as each evaluation lands, with the command that
reproduces them from a clean checkout.
